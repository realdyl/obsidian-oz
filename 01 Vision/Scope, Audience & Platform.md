# Scope, Audience & Platform

## Target Player

- **Age:** 13+ (T-rated target).
- **Likes:** action-adventure, strong art direction, character-led stories, *Hades* / *Kena* / *Zelda*.
- **Session length:** 30–90 minutes; save-anywhere friendly.
- **Skill:** approachable combat; depth from kit choice, not execution barriers.

## Product Shape

| Attribute | Target |
| --- | --- |
| Genre | 3D action-adventure (summon brawler + light stealth) |
| Camera | Third-person, readability-first |
| Campaign | 8–12 hours |
| Structure | 4 regions, hub-free, linear-with-branches |
| Price | Premium (no live-service, no battle pass) |
| Platforms | PC (Steam/Steam Deck) first → PlayStation/Xbox/Switch 2 later |
| Modes | Single-player; New Game+ optional |
| Localization | EN at launch; text-ready for 5+ languages |

## Content Budget (v1)

| Category | Count |
| --- | --- |
| Regions | 4 (Munchkinland, The Wilds, Winkie Country, Emerald City/Quadling) |
| Bosses | 4 + 1 cold-open set piece |
| Companions | 3 (Scarecrow, Tin Man, Lion) |
| Enemy families | 6 + 2 elites |
| Main quests | 4 acts |
| Side quests | 5–8 |
| Playable verbs | Walk/run, blink, long teleport, kick, 3 summon kits |

## In Scope

- Handcrafted linear regions with optional side paths.
- One active summon, AI-driven, player-triggered abilities.
- Diegetic basket inventory + Toto wayfinding.
- Boss-per-companion progression.
- Accessibility suite (see [[Accessibility & Difficulty]]).

## Out of Scope (v1)

- Open world, procedural generation, base building.
- Multiplayer/co-op.
- Full RPG stat/gear systems.
- Branching endings beyond the final choice.
- Voice-acted every line (use barks + narrator + key scenes).
- Console launch simultaneously with PC.

## Cut List (in order, if schedule slips)

1. Side quests beyond 5.
2. Second elite variant per family.
3. New Game+.
4. Alternate costumes.
5. Console ports at launch.
6. One region's optional dungeon.

## Team Assumption

- 2–3 core developers (design/programming/generalist).
- Contract: character/creature art, environment art, animation, audio, UI.
- Timeline modeled in [[Game Plan - Roadmap]] for a 3-person core team.

## Platform Notes

- **PC first** for iteration and demo/Next Fest.
- Steam Deck verified target: 40–60 fps at 900p-class internal resolution.
- Web prototype is a *pitch/demo* option only (see [[Tech Stack Decision]]), not the shipping build.
