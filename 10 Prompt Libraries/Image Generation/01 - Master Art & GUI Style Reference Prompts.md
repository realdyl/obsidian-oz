# 01 — Master Art, Ensemble & GUI Style Reference Prompts

Use these prompts to generate **high-fidelity visual benchmarks** that define the exact aesthetic of *Oz: The Road Home* — so we can mirror the lighting, typography framing, material richness, and UI ornament directly into Godot 4's GUI style guide (`oz_theme_factory.gd`, HUD, Grimoire, Tailor of Vices, and Title/Pause screens).

> [!CAUTION]
> **Baum Public Domain IP Guardrail**: Strictly use L. Frank Baum's 1900 public-domain details (**Silver Shoes**, pale gaunt one-eyed Wicked Witch with umbrella-staff, auburn-haired Glinda, Fighting Trees hurling thorny seed-pods). Never prompt for ruby slippers or green-skinned witches.

## 1. Global Visual DNA (Append to Style-Critical Prompts)
