# Boss Framework

## Design Rules

1. **Teach → Test → Master.** Each boss tests the companion you just earned, then combines with older verbs.
2. **Three phases minimum** (or two for the cold open). Each phase changes *the question*, not just the damage.
3. **Readable telegraphs.** Every lethal move has a 0.6–1.0 s tell with shape + sound.
4. **No one-shots** outside clearly marked grabs (and even those are breakable).
5. **Companion relevance.** There must be a phase where the intended friend trivializes a mechanic — and a phase where ignoring them makes it a slog.
6. **Arena is a character.** Verticality, hazards, and exits tell the story.
7. **Checkpoint on phase transitions** (optionally on retry).
8. **Reward is a verb**, not a stat.

## Phase Template

| Phase | Purpose | Example |
| --- | --- | --- |
| **P1 · Read** | Establish pattern, teach telegraph | Slow wide swings, telegraphed grabs |
| **P2 · Pressure** | Add adds/hazards, force kit use | Summons, arena shrink, aerial phase |
| **P3 · Climax** | Combine everything, emotional peak | Desperation attack, arena destruction |

## Difficulty Knobs

- Telegraph length
- Add frequency
- Arena hazard density
- Phase count (Story mode may merge phases)
- Checkpoint generosity

## Anti-Patterns

- Damage sponges with no new question.
- Unblockable, untelegraphed bursts.
- Adds that exist only to inflate duration.
- Bosses that ignore the game's core verbs (shoes/summons).
- Cutscene deaths that negate player agency.
